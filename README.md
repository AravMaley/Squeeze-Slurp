# Squeeze & Slurp

A simple web application for managing shopping carts, favorites, and promotional codes I have developed while exploring AI and git.
This is my first project. All names and items used here are fictional and do not represent anything from real life.

## Features

- **Shopping Cart** - Add, remove, and track items in your cart
- **Favorites** - Save your favorite items for quick access
- **Promo Codes** - Apply promotional codes to get discounts

## Project Structure

- `index.html` - Main HTML file with the page structure
- `styles.css` - Styling for the application
- `script.js` - JavaScript functionality and interactivity

## Getting Started

1. Open `index.html` in your web browser
2. Start adding items to your cart
3. Add items to favorites by clicking the heart icon
4. Apply promo codes at checkout

## Browser Compatibility

Works on all modern browsers that support ES6 JavaScript.
